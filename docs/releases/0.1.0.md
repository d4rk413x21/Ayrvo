# Ayrvo 0.1.0

The first Ayrvo release brings a new identity, native macOS interface, and a
workflow that connects recorded conversations to reviewed development tasks.
It includes the improvements made since Nutola 0.0.2.

## Highlights

- **Meeting capture and local transcription:** microphone and system audio,
  Apple Speech live previews, and Parakeet Redux or Ultra for final transcription.
- **Reviewed work, with context:** extract development task drafts through a
  supported AI CLI, review transcript quotations, and publish selected issues to
  Linear with saved links and recovery from interrupted exports.
- **A native macOS experience:** a new icon and branding, reorganized settings,
  focused meeting views, and Liquid Glass floating controls.
- **Assistant integration:** a read-only meeting CLI and an MCP connector with
  additional editing and deletion tools.
- **More reliable recording lifecycle:** serialized resume/stop transitions,
  retained elapsed duration, consistent transcript timestamps, and recovery of
  previous capture files when resume fails or is cancelled.
- **Safer persistence:** better protection for unsaved notes and titles, guarded
  processing writes, and corrected task provenance in daily digests.

Google Meet speaker attribution uses Chrome, Accessibility access, and enabled
Meet captions. Transcription remains on-device; AI summaries, chat, and task
extraction follow your selected provider and may send text to a remote model.

## Install

Requires **Apple Silicon and macOS 26 or later**. Download **Ayrvo.zip**, extract
it, and move **Ayrvo.app** to **Applications**. Follow the permissions walkthrough
on first launch. Apple Intelligence is optional.

This build uses ad-hoc signing and is not notarized. macOS may require approval
in **System Settings → Privacy & Security** before opening it.

## Upgrading from Nutola

Quit Nutola before launching Ayrvo. Existing recordings, settings, model downloads,
and Linear credentials retain their existing locations and application identity.
The library remains at `~/Library/Application Support/Nutola/`; back it up before
upgrading. Update old CLI paths to `Ayrvo.app` and reconfigure MCP as `ayrvo` in
**Settings → Intelligence**.

Inherited online note publishing, including `notes.nutola.to` and Gist publishing,
has been removed. Local exports remain available.

## Validation and limitations

The source baseline passed 777 tests across 86 Swift Testing suites in GitHub CI;
three Apple Intelligence tests were skipped because that provider was unavailable.
The release preparation PR also runs the test suite and assembles the versioned
app bundle. Automated checks do not replace recording tests with physical audio
devices, live meeting clients, or a separate macOS 26 installation.
